/punch + /trim + /raw

**/punch** — rewrites for impact and clarity.  
**/trim** — cuts fluff, keeps signal.  
**/raw** — removes corporate speak, makes it sound human.

---

**Prompt:**

```
/punch: Rewrite this for maximum clarity and impact. Lead with the point. Use active verbs. Cut hedging.

/trim: Now cut it by 30-50% without losing the core message. Every word must earn its keep.

/raw: Make it sound like a human wrote it. No "circle back," "align," "leverage," "bandwidth," "touch base." Plain English only.
```

Paste your draft message, run all three. The result is a message people actually read and act on.
